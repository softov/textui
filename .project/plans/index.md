# Plans index

One row per plan; a plan is a folder with `plan.md` and one file per task.
Status: `draft` · `planned` · `active` · `built` · `dropped` (a task: `todo` · `doing` · `done` · `blocked` · `dropped`).
Format and rules: the `do-spec` skill in [`.agents/skills/do-spec/`](../../.agents/skills/do-spec/SKILL.md).
What is not planned yet is one file each under [`roadmap/ideas/`](../../roadmap/ideas/), and a plan starts from one of them.
Decisions live in [`decisions/`](../decisions/), whether or not a plan is open for them.
