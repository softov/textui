# Platform

What surrounds the components: how an action is spelled, how a key reaches it, what has focus, what is drawn on top, and how a screen replaces another.

These are the parts an application configures rather than renders. A command is registered once and a button, a keybinding, a menu entry and the palette all reach it - which is the reason none of them can drift from each other.
